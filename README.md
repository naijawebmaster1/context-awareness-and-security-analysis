# Face Liveness Detection — CASIA-FASD

A face anti-spoofing classifier trained on the [CASIA Face Anti-Spoofing Dataset (FASD)](http://www.cbsr.ia.ac.cn/english/Databases.asp). It extracts handcrafted features from face images and trains a Multi-Layer Perceptron (MLP) to distinguish real (live) faces from spoofed ones (printed photos, replayed video). Three Explainable AI (XAI) methods — Grad-CAM, SHAP, and LIME — are applied to visualize and interpret the model's decisions.

## How it works

1. Each face image is preprocessed with Single-Scale Retinex to normalize lighting
2. Features are extracted using one of five modes:
   - `nn_gradients` — Sobel edge gradient magnitudes
   - `nn_raw_gray` — raw grayscale pixel values
   - `nn_spatial_lbp` — Local Binary Pattern texture descriptors
   - `nn_high_freq` — Laplacian high-frequency response
   - `nn_lpq` — Local Phase Quantization histogram
3. The MLP classifier (`networkb.py`) trains on the extracted features and outputs a live/spoof prediction
4. Performance is measured using APCER, BPCER, and ACER — standard face anti-spoofing metrics
5. XAI methods generate heatmaps overlaid on the original images to explain model decisions

## Step-by-step: how to run

### Step 1 — Train and evaluate the model

Open `main_nn.py` and set `CHOSEN_MODE` at the bottom of the file to your desired feature type:

```python
CHOSEN_MODE = 'nn_gradients'   # or nn_raw_gray, nn_spatial_lbp, nn_high_freq, nn_lpq
```

Then run:

```bash
python3 main_nn.py
```

This extracts features, trains the MLP for 50 epochs, saves the model to `models/liveness_<mode>.pth`, prints APCER/BPCER/ACER to the console, and appends the result to `results.json`. Repeat for each mode you want to evaluate.

To train all five modes back to back:

```bash
for mode in nn_gradients nn_raw_gray nn_spatial_lbp nn_high_freq nn_lpq; do
  python3 -c "
from main_nn import CASIAEvaluator
CASIAEvaluator('./casia-fasd', '$mode').evaluate()
"
done
```

### Step 2 — Plot the results comparison chart

```bash
python3 plot_results.py
```

Reads `results.json` and saves a grouped bar chart of APCER/BPCER/ACER for all trained modes to `xai_output/results_comparison.png`.

### Step 3 — Generate Grad-CAM heatmaps

```bash
python3 xai_gradcam.py
```

Loads each saved model and produces Grad-CAM and Gradient Saliency heatmap overlays for 5 live and 5 spoof test images per mode. Output is saved to `xai_output/gradcam/<mode>/`.

### Step 4 — Generate SHAP attribution maps

```bash
python3 xai_shap.py
```

Runs KernelSHAP (200 coalitions, 100-sample background) for each test image and saves heatmap overlays to `xai_output/shap/<mode>/`. This is the slowest step — expect several minutes per mode.

### Step 5 — Generate LIME explanations

```bash
python3 xai_lime.py
```

Runs LIME (1,000 perturbations, top-50 features) for each test image and saves heatmap overlays to `xai_output/lime/<mode>/`.

### Step 6 — Generate the side-by-side XAI comparison

```bash
python3 xai_compare.py
```

Runs all three XAI methods on one live and one spoof image per mode and produces a 4-panel comparison figure (Original | Grad-CAM | SHAP | LIME) saved to `xai_output/comparison/<mode>/`. Also prints and saves a written comparative analysis report to `xai_output/comparison/xai_comparative_analysis.txt`.

### Step 7 (optional) — Real-time webcam demo

Requires a trained model for `nn_gradients` mode (`models/liveness_nn_gradients.pth`).

```bash
python3 demo.py
```

Opens your webcam, detects faces using Haar cascades, and overlays a live/spoof label with confidence score in real time. Press `Q` to quit.

## Metrics

| Metric | Meaning |
|--------|---------|
| APCER | Attack Presentation Classification Error Rate — spoof classified as live |
| BPCER | Bona-fide Presentation Classification Error Rate — live classified as spoof |
| ACER | Average of APCER and BPCER — overall error rate (lower is better) |

## Results

| Mode | APCER (%) | BPCER (%) | ACER (%) | Rank |
|---|---|---|---|---|
| `nn_lpq` | 5.54 | 18.11 | 11.83 | 1 (Best) |
| `nn_raw_gray` | 6.91 | 19.37 | 13.14 | 2 |
| `nn_gradients` | 6.80 | 20.28 | 13.54 | 3 |
| `nn_high_freq` | 9.64 | 19.24 | 14.44 | 4 |
